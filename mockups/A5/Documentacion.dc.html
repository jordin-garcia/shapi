API de Cotización de Envíos

POST

/cotizaciones

Calcula el costo de un envío según origen, destino, peso y tipo de servicio.

https://envios.api.shapi.localhost/cotizaciones Descuenta 1 llamada de su cuota
Probar en la consola

Parámetros

Parámetro Tipo Obligatorio Descripción
origen texto Sí Código del municipio de origen
destino texto Sí Código del municipio de destino
peso_kg número Sí Peso del paquete en kilogramos
tipo_servicio texto No Normal o urgente. Si se omite, se cotiza como normal
Petición POST  /cotizaciones
{ "origen": "0901", "destino": "0301", "peso_kg": 2.5, "tipo_servicio": "normal" }
Respuesta 200
{ "origen": "Quetzaltenango", "destino": "Antigua Guatemala", "tarifa": "Q 38.50", "entrega_estimada": "2 días hábiles" }
