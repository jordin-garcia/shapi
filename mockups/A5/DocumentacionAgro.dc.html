API de Precios de Mercado

GET

/precios

Devuelve el precio del día de un producto en un mercado.

https://agro.api.shapi.localhost/precios Descuenta 1 llamada de su cuota
Probar en la consola

Parámetros

Parámetro Tipo Obligatorio Descripción
producto texto Sí Clave del producto
mercado texto Sí Clave del mercado mayorista
fecha texto No Fecha del precio. Si se omite, se devuelve el precio del día
Petición GET  /precios
{ "producto": "frijol_negro", "mercado": "cenma" }
Respuesta 200
{ "producto": "Frijol negro", "mercado": "CENMA", "unidad": "quintal", "precio": "Q 510.00", "fecha": "10 sep 2026" }
