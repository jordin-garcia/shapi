## 4. Criterio 5: llaves de Data Protection en desarrollo

**Hallazgo de JZ-15 (1 nov):** con `SHAPI_DPKEYS_DIR=.shapi/dpkeys`, cada proceso resolvía la ruta desde su carpeta de inicio. Con `dotnet run`, esas carpetas eran `src/Shapi.Api/.shapi/dpkeys` y `src/Shapi.Trabajador/.shapi/dpkeys`, así que había dos anillos de llaves. El trabajador no podía descifrar el secreto de origen que cifró la API y, al resincronizar, conservaba lo que había publicado la API y registraba un error.

**Corrección:** `DirectorioLlaves.Resolver` (`src/Shapi.Infraestructura/Comun/`):
- usa tal cual una ruta absoluta;
- resuelve una relativa desde la raíz del repositorio, la primera carpeta superior con `Shapi.slnx`;
- fuera del repositorio, la resuelve desde la carpeta de inicio del proceso.
